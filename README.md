# Peter Musa (Pe6tens) – Personal Portfolio Website

## 1. Project Overview

This project is a personal portfolio website developed by Peter Musa, also known online as Pe6tens. Peter is a 100-level Computer Science student at Miva Open University, and a digital artist and graphic designer based in Jos, Nigeria, working toward a career in full stack development, UI/UX design and game development.

The website showcases my personal background, educational journey, skills, hobbies, projects, artwork and professional aspirations.

It was developed as my term project for Introduction to Web Technologies (MIVA-CSC 106).

## 2. Project Purpose

The purpose of this project is to:

- Build and demonstrate practical web development skills.
- Create a professional online presence for my art and design work.
- Showcase my academic background, projects and artwork.
- Practise HTML, CSS and JavaScript.
- Develop a responsive and mobile-friendly website.
- Build a working academic planner that helps me manage my studies.

## 3. Technologies Used

- HTML5: Used to structure the website content with semantic elements, tables, lists, forms, images and audio.
- CSS3: Used for styling, layout (Flexbox and CSS Grid), animations and responsive design.
- JavaScript: Used for the typing effect, art gallery, task manager, timetable and form validation. No frameworks or libraries.
- Git and GitHub: Used for version control and project hosting.
- GitHub Pages: Used to publish the website online.

## 4. Website Pages and Features

The website consists of five separate pages that share one stylesheet and one script file:

### Home Page

- Name and profile photograph.
- Welcome message and brief biography.
- Navigation menu.
- Animated typing line describing what I do.
- Personal motto.
- Audio introduction with a written transcript.

### About Me Page

- Personal background and story.
- Educational background (table).
- Career aspirations.
- Technical and creative skills.
- Hobbies and interests.
- The story behind the name Pe6tens.

### Projects Page

- Displays four projects with screenshots or images.
- Includes project descriptions and the tools used.
- Provides links to the art collection, the planner and the GitHub repository.
- Art gallery with four tabs and a full-screen viewer (see Section 5).

### Academic Planner

- Task manager where tasks can be added, marked as completed and deleted.
- Optional course and due date for each task, with filters (all, to do, done).
- Tasks are saved in the browser, so they are still there when I return.
- Weekly study timetable with today's rows highlighted.
- Course table with total units.

### Contact Page

- Contact form with name, email address, phone number and message.
- JavaScript validation: no field can be empty, the email format must be valid and the phone number must contain only digits.
- Clear error messages shown beside each field.

## 6. Project Structure

The project contains the following main files:

- "index.html" – Home page.
- "about.html" – About Me page.
- "projects.html" – Projects page.
- "planner.html" – Academic Planner page.
- "contact.html" – Contact page.
- "style.css" – Website styling. Colours and fonts are set at the top under `:root`.
- "script.js" – JavaScript for the typing effect, art gallery, planner, timetable and contact form validation.
